# Conflicting signals

An older team guide says run `npm test` and links to `https://old-jira.internal.example/browse/APP-1` (self-hosted Server/DC inference). The current contributor guide says run `npx playwright test` and links to `https://new-team.atlassian.net/browse/APP-1` (Cloud inference). These are intentionally incompatible; Configure must show both and ask, not pick one silently.
